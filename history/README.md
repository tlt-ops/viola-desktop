# Viola 历史版本归档

本分支保存清理前能恢复的旧应用、源码快照、角色素材与发行包。当前产品源码仍在仓库的 `main` 分支，最新正式发布为 [v0.2.50](https://github.com/tlt-ops/viola-desktop/releases/tag/v0.2.50)。

- [版本与快照索引](versions.json)记录旧应用实际版本、构建号、文件数和源码完整性。
- [早期发行包索引](historical-releases.json)记录 14 个应用 ZIP 和 1 个布局 ZIP；版本取自包内 Info.plist，全部 ZIP 成员 CRC 已检查。
- [逐文件校验清单](files.sha256.json)记录相对路径、文件大小、Git 权限和 SHA-256。
- `cache/` 保留后期开发缓存中的可恢复版本；`legacy-workspace/` 保留更早工作区中的源码、艺术素材、旧发行包与应用；`installed-apps/` 保留独立安装的 0.2.22 保留版。

同内容文件由 Git 按内容去重，原有不同路径和可执行权限仍保留。不同姿势、笑声、手臂、桌子与动作修改前后的快照均按实际保存状态归档，未将版本号相同的包自动合并。部分 source-before 只有当时修改的文件，索引明确标为局部源码；没有宣称这些局部快照可以独立编译。旧应用按原包内容保存，未逐版重新运行或重新签名。

个人配置、按键统计、诊断与桌面截图不在公开归档内。旧文档和素材来源记录里的本机绝对路径已处理为相对路径或文件名，原有素材来源链接和素材校验值保留；应用、角色图片及已审核的旧发行 ZIP 保持原字节。可重建的编译缓存、重复逐帧预览和完整来源视频没有作为历史发行内容上传。

## 取回归档

```sh
git clone --single-branch --branch codex/viola-history-20261008 https://github.com/tlt-ops/viola-desktop.git viola-history
```

按版本索引找到需要的应用或 ZIP。应用目录应整体复制，保留 `Contents` 下的所有文件和主可执行文件权限。角色布局与 `character-assets` 可按对应快照恢复；避免将不同版本的局部源码拼成一个未经验证的版本。最新版的构建、使用和 Windows 安装方法见仓库根目录 README。
