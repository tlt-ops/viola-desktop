# 键盘、左手分区与累计统计

## 共用映射

`Sources/ViolaCore/Keyboard.swift` 中的 `KeyboardLayout` 同时定义物理键码、键帽位置、宽度及负责手指。键帽绘制、按压反馈、手掌定位与手指指令使用同一份映射。字符输入法不影响物理键的位置；例如中文输入法下按下物理 A 键，仍反馈 A 位置。

| 手指 | 主要区域 |
|---|---|
| 左小指 | Esc、1、Q A Z、Tab、Caps、左 Shift/Ctrl、fn |
| 左无名指 | 2、W S X |
| 左中指 | 3、E D C |
| 左食指 | 4 5、R T F G V B，以及整个右半区：6–0、Y U I O P H J K L N M、标点、Enter、Backspace、右 Shift、方向与导航键 |
| 左拇指 | Space、两侧 Command、两侧 Option |

功能键也有明确的分区，可在统计窗口逐键查看。全部可视键均由左手操作；右手始终握着鼠标。左掌在整个键盘上移动，左食指覆盖右半区，Space 由左拇指负责。这里的分区定义薇欧拉的动画动作；键盘事件本身无法识别用户实际用了哪根手指。

## 动作指令

`AnimationFrame.keyPressures` 驱动每个键帽。`fingerPressures` 和 `fingerKeys` 分别驱动五根左手手指的按压量和目标键。角色清单中每个左手手指拥有独立的图层、指根支点、指尖接触点及 `finger` 标识。指根跟随手掌，选中的手指独立下压。

左掌朝最近的目标键插值移动，目标点取自实际键帽区域，包含键盘外层 −18° 倾角、内层 180° 朝向旋转和键帽下沉。左上臂的肩部保持连接；肘部跟随 58% 的横向位移，前臂承担余下位移并随距离缩短，袖口保持与左掌同向。右手握持组合只响应鼠标移动和点击；打字时保持显示，键鼠可以同时动作。组合键的键帽和左手手指状态独立反馈；左掌优先朝最近的键定位，同一根手指同时负责多个按住的键时，目标使用最近的一个键。当前是二维精灵指法动画，并非完整的手部三维逆运动学模拟。

## 统计

键盘整体位于桌面左侧，按键和文字朝向薇欧拉：空格靠近她，功能键靠近桌前，鼠标握持组合在右前侧。目标位置从当前键盘图层转换到画布，因此调整键盘位置、尺寸或倾角会同步调整指尖落点。键帽下沉量也计入接触点。鼠标袖子的肩部保持原位置，握持组合的静态偏移和鼠标移动量共同决定袖口位置。

菜单或设置中的「键位统计」显示各键的累计按下次数、连发次数与负责手指。初次按下增加 `presses`，系统自动连发增加 `repeats`，松开不增加计数。演示直接送入动画引擎，不经过真实输入统计。

新版统计路径：`~/Library/Application Support/ViolaDesktop-Preview/keyboard-stats.json`；旧版仍使用 `ViolaDesktop`。只保存各物理键的累计次数；不保存字符、输入文本、按键顺序或逐次时间戳。重新打开应用会恢复统计。

可视键盘采用紧凑 ANSI 主键区及功能/导航键。小键盘、ISO/JIS 扩展位置保留统计，当前不在主键盘上绘制；未映射到可视键盘的码不会误点其他键。系统直接处理的亮度、媒体等特殊事件不属于当前普通键码监听范围。

## 验证

运行 `swift run ViolaChecks`。核心检查遍历每个可视键，确认只有对应键帽及分配手指激活，检查独立组合键、松开恢复、按下/连发分别计数及统计序列化。

`--render-gallery` 导出每根手指的单独动作图、`key-bindings.json` 及连续动作。它们用于查看真实渲染器的姿势与映射。全局输入需要在运行中的已授权应用上检查，不能用演示代替。

导出的 `key-contact-geometry.json` 逐键记录实际左手指尖和键帽接触点，以及右手鼠标握持的显示状态和位置误差。任何可视键在插值稳定后接触误差超过 0.1 逻辑点，或打字导致右手握持隐藏/移位，都会中断导出。该检查覆盖主键区、修饰键、功能键与边缘导航键。`key-38.png`、`key-40.png`、`key-37.png`、`key-36.png`、`key-49.png` 分别展示 J/K/L/Enter/Space 的左手落点。

## 0.2.6 向内拼装的双桌与行程

键盘外框为 `[179.873, 400.214, 250, 80]`，倾角 −18°。左、右桌板向薇欧拉身体两侧内收，前方中央接合成浅 U 形。键盘、手腕、鼠标和下方坐姿已同步对齐。

82 键的左腕横向跨度由 373.31 降至 255.87 逻辑点（减少 31.46%）；肩部到手腕的最大横向偏移由 208.61 降至 149.32（减少 28.42%）。数据来自稳定后的实际渲染几何。最初向外展开的候选布局数据保留在旧证据文件中，当前结果以 `keyboard-reach-inward-v0.2.6.json` 为准。
