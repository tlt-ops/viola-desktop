# 自由缩放

- 鼠标放在伙伴窗口上，直接滚轮连续放大或缩小；Option + 滚轮也继续可用。触控板上下滑动连续缩放，捏合手势同样可用。惯性滚动不继续改变大小。
- 右键伙伴或打开菜单栏，进入「大小」：放大 10%、缩小 10%、50/75/100/125/150/200% 预设，以及恢复默认大小。菜单显示当前百分比。
- 设置中的大小滑杆实时调整，显示相对默认大小的百分比及窗口宽度。默认宽度 440 点，范围 160–1200 点；上限同时受所在屏幕可用宽高限制。窗口尺寸使用 macOS 逻辑点（pt），与 Retina 实际像素不同。
- 缩放保持原始画布比例，以窗口底边中心为固定锚点；到屏幕边缘时自动移回可见范围。每次大小调整同时保存尺寸和位置，重启恢复。
- 开启鼠标穿透时，通过菜单栏「大小」或设置滑杆调整；穿透窗口不会接收滚轮、捏合或右键。

新版人物加入的脚趾细微活动使用局部网格动画，不改动源位图。每侧 723 帧渲染检查测得自由状态最大变形为画布上的 0.8447326674 px，贴合状态为 0.1267099001 px；减少动态效果时严格为零。锚定的小腿和鞋不随变形移动。原生减少动态设置已确认关闭双侧趾动。

0.2.17 build 18 原生菜单缩放已验收：75% 得到 330 pt，退出并重新打开后仍为 330 pt；滚轮将尺寸调至 403.062910 pt，窗口显示为 404×484。验收后已恢复原有尺寸约 362.756619 pt（窗口 363×436）与原位置，位置存在不超过 1 pt 的原生取整差异。触控板滑动/捏合及断开显示器后的恢复本版尚未实际操作验收。全量验收状态见 [验收记录](ACCEPTANCE.md)。
