# 0.2.12 大笑互动

## 使用

- 点击薇欧拉头部或上半身；拖动超过 5 屏幕点则移动窗口，不触发笑。
- 右键菜单和菜单栏增加「让薇欧拉大笑」。鼠标穿透时使用菜单栏。
- 未收到键鼠活动 45 秒后自动触发；上一段结束后有 90 秒自动触发冷却。
- 每段 5.6 秒，前 0.42 秒渐入、后 0.7 秒渐出。动作进行中不会被重复点击重启。
- 双手捂住腹部，闭眼张嘴大笑，上身颤动。小腿前后摆幅 0.82/0.76 弧度，左右摆幅 0.15/0.14 弧度；膝盖保留接点。
- 紫发女孩切换吃力表情，头、脸部贴片和支撑身体统一倾斜。以地面附近为变形基线，避免手掌整体滑离地面。
- 鼠标离手后停留在原桌面位置；结束后手臂和鼠标恢复通常互动。键位统计持续接收真实事件。
- 正在穿鞋时点击大笑会排队，等穿鞋完成。大笑期间落地的鞋先停留在地上；点击鞋子会排队至笑完再拾回。
- 减少动态效果将身体和腿部摆幅降至 35%。

## 实现

`AnimationEngine` 提供 Laugh 状态、触发来源、动作包络、身体颤动和支撑角色倾斜值。渲染器独立消费这些数值；按键和鼠标监听不承担动画计时。

## 手动验收步骤

1. 点击薇欧拉的脸：应笑约 5.6 秒，双手捂腹、双腿前后及左右摆动、紫发女孩吃力摇晃；动作结束恢复键鼠姿势。
2. 拖动角色：应移动窗口，不误触大笑。点击键盘、鼠标桌、朋友或鞋子不应触发大笑。
3. 使用菜单「让薇欧拉大笑」；鼠标穿透时使用菜单栏。连续点击不应重播到开头。
4. 输入监控正常连接后，停止实体键鼠操作 45 秒，观察自动大笑；随后保持空闲，90 秒冷却结束前不应再次自动笑。
5. 穿鞋过程中点击：等待穿鞋结束后播放大笑。大笑时点击地上的鞋，应在结束后拾回。
6. 启用减少动态效果，确认腿和支撑角色摆幅降低；恢复后摆幅恢复。

全局键盘是否接入，以应用的实时权限状态和实体键盘响应为准；美术导出不能证明该权限已生效。

## 本地大笑声音

大笑状态开始时由 AVAudioPlayer 播放一次奶龙笑声，点击、菜单、空闲以及穿鞋后排队的大笑共用同一入口。每帧不重复启动，声音不叠加；动作结束、收起伙伴、重置动作和退出应用会停止声音。菜单「大笑声音」开关及设置音量保存在当前应用配置。旧版本配置无需迁移，默认开启、音量 80%。播放期间关闭再开启声音不会重播当前段落，下一次大笑生效。

优先读取当前应用 profile 下 `Sounds/nailong-laugh.m4a`（也支持 wav/mp3），随后读取 profile 根目录同名文件，最后读取角色资源目录 `Sounds/`。若优先文件无效，则尝试下一个文件。每次开始重新载入文件，替换外部音频后下一段即可使用。

当前使用的 5.6 秒声音来自 [naiwa-pet 的 laugh.m4a](https://github.com/Diyeego/naiwa-pet/blob/main/naiwa/laugh.m4a)，原文件保留于 `Assets/Audio/nailong-laugh-source.m4a`；裁掉开头 2.04 秒静音，剪为动画时长，35ms 淡入、250ms 淡出。处理后的本地文件为 `Assets/Audio/nailong-laugh.m4a`，打包副本位于 `Sources/ViolaDesktop/Resources/Characters/Viola/Sounds/`，沿用既有角色资源打包。

`diagnostics.json` 的 `laughAudio` 记录实际使用的路径、播放状态、启动次数和失败原因。没有文件或解码失败时动画继续运行，诊断给出原因。声音播放的实体听感及全局键鼠权限需要在实际安装后验收；编译不能证明这两项。
