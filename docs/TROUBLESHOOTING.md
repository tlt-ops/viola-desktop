# 故障排查

## 打字时角色不动

先试菜单里的 10 秒演示，确认渲染能运行；再确认“键鼠互动”已启用。打开“系统设置 → 隐私与安全性 → 输入监控”，确认你实际运行的应用已获授权，在应用设置中重新连接输入，必要时退出并重启。更换应用位置、重新构建或改变签名后，权限记录可能需要重新确认。没有权限时鼠标和应用内输入的降级行为不等于已连接全局键盘。

检查诊断的 `inputPermission` 与 `globalKeyboardConnected`；即使前者为真，tap 创建失败时后者仍可能为假。不要为了此应用额外授予屏幕录制或麦克风权限。

## 看不到角色或无法点击

从菜单栏选择显示角色、恢复默认位置，并检查尺寸；外接屏幕拔插后也可重置位置。启用鼠标穿透时请从菜单栏关闭穿透。应用作为菜单栏伙伴运行，不依赖 Dock 图标。隐藏窗口不会关闭键位统计，若要暂停统计请关闭互动。

## 没有笑声

确认“大笑声音”启用、音量大于零和系统输出设备可用。笑声只在进入大笑状态时启动，不会因在同一段大笑中重新打开声音而自动重播。切换“奶龙大笑 / 薇欧拉大笑”会立即停止旧声音，并从下一次大笑生效；选定音源缺失或播放失败不会自动播放另一音源。检查 `laughAudio.failure`（Windows 查看菜单状态）；本地音频覆盖的命名和搜索顺序见 [架构](ARCHITECTURE.md)。

## 爬行按钮不可用或自动爬行中断

大笑、穿鞋、正在打字或仍按住键时可能无法开始爬行；需要当前鞋子处于可爬行的穿着状态。等待动作结束后重试。闲置爬行使用系统输入年龄，真实输入会使它回位，菜单打开、拖动及其他状态变化也可取消动作。减少动作模式会限制爬行位移。

## 无法加载角色

检查构建是否包含角色 `character.json` 和全部引用的图片。若使用外部 `character-layout.json`，先退出并备份该覆盖文件，再暂时移出 profile，使用包内默认布局确认问题范围。不要直接修改已签名的 `.app` 内文件；从源码重建或使用外部覆盖。

## 视觉接缝与平台范围

当前版本在大笑结束的短暂回位中，颈胸贴图混合可能出现接缝。此问题属于已知视觉限制。渲染/核心检查不能覆盖所有实时帧、显示缩放、多屏边界或硬件帧率；反馈时请说明 macOS、芯片、显示缩放、动作触发与复现步骤，并提供必要的短视频或局部截图。

## macOS 阻止打开

当前自行构建产物使用 ad-hoc 签名，没有 Developer ID 签名和 Apple 公证。确认来源后，可尝试 Finder 右键“打开”或“系统设置 → 隐私与安全性”中的打开选项。请勿关闭整机安全保护作为排查方式。

公开 issue 前参照 [隐私说明](PRIVACY.md) 脱敏诊断，尤其是素材/音频路径、窗口轨迹和用户名。
